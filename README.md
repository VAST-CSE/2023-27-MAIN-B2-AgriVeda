# 🌱 AgriVeda – Smart Agricultural Scheme Assistant

AgriVeda is a web-based platform designed to provide easy access to agricultural scheme information for **farmers as well as common people**. It centralizes scheme details and enhances accessibility through **multilingual support, voice assistance, and chatbot integration**.

---

## 🚀 Features

- 📍 District-wise scheme filtering  
- 📄 Detailed scheme information (eligibility, benefits, documents)  
- 🌐 Multi-language support (English → Malayalam)  
- 🎤 Voice-based assistance  
- 🤖 Chatbot for instant query resolution  
- 🧑‍💻 User-friendly interface  
- 📚 Centralized information system  

---

## 🛠️ Tech Stack

### Frontend
- HTML  
- CSS  
- JavaScript  
- Bootstrap / Tailwind CSS  

### Backend
- Django (Python Framework)  

### Database
- SQLite / PostgreSQL  

### APIs & Tools
- OpenAI API (Chatbot)  
- Speech Recognition API (Voice Input)  
- Translation API (Malayalam Support)  
- Git & GitHub  

---

## 🧠 How It Works

1. User selects district or enters query  
2. Backend (Django) processes request  
3. Data is fetched from database or API  
4. Response is displayed on UI  

For voice input:
- Speech → Text → Process → Response
